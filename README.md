# web-discovery-agent

A bot that scrapes legitimate public sources for each Merch-supported college, finds real freebie/event opportunities, and feeds them into the existing discovery pipeline (candidates → review → publish).

See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for goals, acceptance criteria, and the phased roadmap.

**Principle:** correctness before volume. Low-confidence candidates go to human review, never auto-publish.
